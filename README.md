# Gemini AI Chatbot

A simple AI chatbot built using Google's Gemini API and Gradio.

## Features

- AI-powered conversations using Gemini
- Clean and modern user interface
- Real-time responses
- Clear Chat option
- Simple and easy-to-use design

## Technologies Used

- Python
- Google Gemini API
- Google GenAI SDK
- Gradio

## How to Run

1. Create and activate a Python virtual environment.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Enter your Gemini API key when prompted.
5. Open the local Gradio URL in your browser.

## Project Purpose

This project demonstrates how Generative AI can be integrated into a Python application to create an interactive AI chatbot.
